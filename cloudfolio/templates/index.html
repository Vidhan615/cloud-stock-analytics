What these numbers mean

TREND

Simple moving average

The mean of the last 20 closes. It smooths fluctuations, but lags the latest price. The first 19 values need a warm-up.

RECENT WEIGHT

Exponential moving average

An EMA gives newer prices more weight. This implementation starts from the first close and uses a 20-session span.

MOMENTUM

Relative strength index

Wilder’s 14-session gain/loss smoothing. A reading above 70 can persist in a strong trend; flat prices return 50.

BEHIND THE WORKSPACE

A cloud project you can trace.

From browser request to database record to private object storage.

AWS deployment blueprint
This view explains the architecture. It does not claim that this preview is running on AWS.
01 · PRESENTATION

Browser dashboard

HTML · CSS · JavaScript · SVG charts

↓ HTTPS / JSON
AWS · ap-south-1
02 · APPLICATION

ALB → EC2 → Gunicorn + Flask

TLS termination · private app port · instance role

↓ Validated requests & authenticated writes
03 · DATABASE

Amazon RDS · MySQL

Private subnets · encrypted storage
Users, holdings, watchlist, audit records

03 · OBJECT STORAGE

Amazon S3 · Private bucket

Versioned CSV exports & chart files
Dataset backups · encryption · lifecycle rules

⌘

Infrastructure as code

A CloudFormation template defines networking, compute, RDS, S3, IAM, the load balancer and monitoring. Provisioning is explicit and repeatable.

◇

Defense in layers

Private database ingress, IMDSv2, TLS, signed HttpOnly cookies, CSRF checks, hashed passwords and user-scoped queries.

↻

Operate, then observe

Liveness and readiness checks, request IDs, structured application logs, CloudWatch collection and a weekly dataset backup job.

▦

Start locally

SQLite for a quick start. Docker Compose adds MySQL. The same relational models and API power the AWS configuration.

Application code, tests, Docker, AWS configuration and deployment runbooks.
